# Career Change to Tech — a Realistic 6-Month Roadmap

A honest, free **roadmap for changing careers into tech** as a working adult — what to learn, in what order, how many hours it really takes, and how to get the first job without a computer science degree.

Maintained by [Korra Academy](https://korra.academy/) — the team behind **[Korra.Career](https://korra.career/)**, live mentoring for career changers.

## Who this is for

You have a job, limited evenings, and no CS degree. You want a tech role — software development, data, IT support, cyber security or QA — within 6–12 months. This roadmap assumes **8–10 focused hours per week**. More hours shortens it; fewer lengthens it. Neither is failure.

## Step 0 — Pick a lane (week 1, don't skip)

Most career changers stall by learning "coding" in general. Pick ONE:

| Lane | Good fit if you… | First job titles |
|---|---|---|
| **Web development** | like building visible things | junior frontend dev, web developer |
| **Data** | like spreadsheets and questions | data analyst, junior data engineer |
| **IT & support** | like fixing things for people | service desk, IT technician |
| **Cyber security** | like how things break | SOC analyst (usually via IT first — see our [it-certification-roadmap](https://github.com/korra-academy/it-certification-roadmap)) |
| **QA / testing** | are detail-obsessed | junior QA, test analyst |

Try a free taster of each for 2–3 hours before committing.

## The 6-month plan (web development lane shown)

### Months 1–2 — Foundations
- HTML, CSS, then JavaScript fundamentals: variables, functions, loops, arrays, objects, DOM.
- Build tiny things weekly; typing code beats watching videos 10:1. Our [vibe-coding-starter-prompts](https://github.com/korra-academy/vibe-coding-starter-prompts) shows how to use AI as a tutor, not a crutch.
- **Milestone:** a personal page + 3 small interactive pages, written by hand, live on GitHub Pages.

### Months 3–4 — Real projects + one framework
- Git and GitHub daily. One framework (React or Svelte — pick by local job ads).
- Build 2 portfolio projects that solve a real problem from your CURRENT industry — your unfair advantage is domain knowledge (a rota tool for nurses beats a 400th todo app).
- **Milestone:** 2 deployed projects with READMEs explaining the problem, decisions and trade-offs.

### Month 5 — The job layer
- Polish GitHub profile + LinkedIn ("career changer with X years in [industry]" is a pitch, not a confession).
- CV: skills + projects first, career history reframed around transferable evidence.
- Start applying at ~70% ready. Applications are practice; feedback is data.

### Month 6 — Interview reps
- Daily: one small coding exercise; weekly: one mock interview out loud.
- Learn to talk through a project: problem → options → choice → result.
- Keep shipping small commits; a live GitHub streak answers "but can they actually code?".

## What actually gets people hired

1. **Proof of work** — deployed projects with readable code and honest READMEs.
2. **Domain crossover** — ex-teacher building edtech, ex-logistics building inventory tools.
3. **A human network** — one coffee chat a week beats 50 cold applications.
4. **Consistency** — 90 minutes daily beats 10-hour Sundays.

## FAQ

**Can I get into tech without a degree?**
Yes — a large share of working developers have no CS degree. Evidence of building (portfolio + GitHub) plus interview competence is the actual bar at most companies.

**Am I too old to switch to tech at 30/40/50?**
No. Career changers bring work discipline, communication and domain knowledge juniors lack. The roadmap is identical; the pitch is stronger.

**Bootcamp, degree, or self-taught?**
Self-taught with structure and feedback is the cheapest path that works. Bootcamps buy pace and accountability. If you want the accountability without the bootcamp price, that's what mentoring at [korra.career](https://korra.career/) is for.

**Which language should I learn first?**
JavaScript for web, Python for data. Don't relitigate this weekly — the second language is 5× easier.
